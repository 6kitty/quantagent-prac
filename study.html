★ 변동성 돌파 전략 (Volatility Breakout)

Larry Williams · 국내 퀀트 커뮤니티에서 가장 많이 회자되는 전략
핵심 아이디어
전일 변동폭(고가-저가)의 일정 비율(k)만큼 시가를 초과하면 돌파로 판단하고 매수
매수 시점
당일 가격 ≥ 당일 시가 + (전일 고가 – 전일 저가) × k
매도 시점
당일 장 마감 (종가 청산) — 오버나이트 리스크 제거
k 값
0.4~0.6 범위가 일반적; 작을수록 신호 많고 노이즈 증가
target_price = open + (prev_high - prev_low) × k
왜 작동하는가? 변동폭이 크다는 것은 관심과 에너지가 집중됐다는 의미. 그 에너지가 특정 방향으로 터지면(돌파) 모멘텀이 이어질 가능성이 높음. 단, 횡보장·박스권에서는 성과가 약함 → ATR 조건 추가로 필터링 권장
DATA 가격 데이터 구조
▶
OHLCV
Open 시가 / High 고가 / Low 저가 / Close 종가 / Volume 거래량. 캔들 차트의 기본 단위
Bid / Ask
매수호가(Bid) = 사려는 가격 / 매도호가(Ask) = 팔려는 가격. 스프레드(Ask-Bid)가 클수록 유동성 낮음
수정주가
배당, 액면분할, 무상증자 등 이벤트 발생 시 과거 주가를 소급 조정한 가격. 백테스팅에는 반드시 수정주가 사용
Tick 데이터
모든 개별 체결 기록(시간·가격·수량). OHLCV보다 세밀하지만 데이터량이 압도적으로 큼. HFT에서 주로 활용
실무 팁: KIS API 일봉은 수정주가 옵션 제공. 백테스팅 시 adj_close 컬럼 사용 필수. 미수정 종가로 백테스트하면 수익률 왜곡 발생
TECH 기술적 분석
▶
SMA
단순이동평균. N일간 종가 합계 ÷ N. 과거 가격에 동일 가중치
EMA
지수이동평균. 최근 데이터에 더 높은 가중치. α = 2/(N+1). SMA보다 빠르게 반응
볼린저밴드
중심선(20일 SMA) ± 2σ. 가격의 95% 구간. 밴드 수축 = 변동성 감소 → 큰 움직임 예고
RSI
상대강도지수(0~100). 14일 기준. 70 이상 과매수, 30 이하 과매도. 추세 강도 측정
MACD
12일EMA − 26일EMA = MACD선. MACD의 9일EMA = Signal선. 골든크로스(MACD>Signal) 매수 신호
ATR
Average True Range. 일별 실제 변동폭 평균. 변동성 돌파 k 값 조합에 자주 쓰임
RSI = 100 − (100 ÷ (1 + 평균상승폭/평균하락폭))
TA-Lib에서: talib.RSI(close, timeperiod=14) / talib.MACD(close) / talib.BBANDS(close). 150개 지표 모두 동일한 인터페이스로 호출
EQUITY 주식 기초 (Equities)
▶
시가총액
현재 주가 × 총 발행주식수. 삼성전자 ~400조. 시총 규모로 대형주/중형주/소형주 구분
PER
주가수익비율 = 주가 ÷ EPS. 낮을수록 저평가 가능성. 업종 평균과 비교해야 의미 있음. 성장주는 PER 높아도 정당화 가능
PBR
주가순자산비율 = 주가 ÷ BPS. 1 미만이면 청산가치 이하. 금융주 밸류에이션에 주로 사용
EV/EBITDA
기업가치(시총+순차입금) ÷ EBITDA. 자본구조 무관한 기업가치 비교에 유용. M&A 시 자주 쓰임
EPS
주당순이익 = 당기순이익 ÷ 발행주식수. 어닝 서프라이즈/쇼크가 주가에 큰 영향
배당수익률
DPS(주당배당금) ÷ 주가 × 100. 한국 평균 약 2%. 고배당주 스크리닝에 활용
팩터 투자 연결: 낮은 PER·PBR = 밸류 팩터 / 높은 ROE·EPS 성장 = 퀄리티 팩터 / 52주 수익률 상위 = 모멘텀 팩터
FUND 기업 펀더멘털
▶
손익계산서
매출액 → 매출원가 → 매출총이익 → 영업이익(EBIT) → 순이익. 분기/연간 발표. 영업이익률이 핵심 지표
대차대조표
자산 = 부채 + 자본. 유동자산/비유동자산, 단기부채/장기부채 구분. 재무 건전성 파악
현금흐름표
영업CF(실제 현금 창출력), 투자CF(CAPEX 등), 재무CF(차입/배당). 순이익보다 FCF(잉여현금흐름)가 더 중요한 지표
ROE
자기자본이익률 = 순이익 ÷ 자기자본. 15% 이상이면 우량. 버핏이 선호하는 지표
부채비율
총부채 ÷ 자기자본. 200% 이하를 건전하다고 봄. 업종별로 기준 다름(금융업 제외)
DART 연결: 금융감독원 DART API로 상장사 재무제표 무료 수집 가능. FSS_API_KEY 필요
BOND 채권 / 금리
▶
YTM
만기수익률(Yield To Maturity). 채권을 만기까지 보유 시 연평균 수익률. 채권 가격과 역방향 관계
Yield Curve
만기별 금리 구조. 정상: 장기>단기(우상향). 역전(Inverted): 단기>장기 → 경기침체 선행지표. 2022~2023 미국 역전 사례
Duration
금리 변동에 대한 채권 가격 민감도. Duration 5 = 금리 1%p 상승 시 가격 약 5% 하락. 장기채일수록 큼
신용스프레드
회사채 YTM – 국채 YTM. 스프레드 확대 = 신용 리스크 증가 = 주식 시장에도 부정적 신호
BOK API 연결: 한국은행 ECOS API(BOK_API_KEY)로 기준금리, 국채금리, 통안채금리 등 실시간 수집 가능
FX 외환 (FX)
▶
직접 호가
자국 통화 기준. USD/KRW = 1달러당 원화. 한국에서는 직접 호가 방식(1 USD = 1,350 KRW)
간접 호가
외국 통화 기준. EUR/USD = 1유로당 달러. 유로존 통화에서 주로 사용
스팟 환율
현재 즉시 결제 기준 환율. 거래 후 T+2 결제가 관행
포워드 환율
미래 특정 시점의 환율을 지금 확정. 환 헤지 목적. F = S × (1+r_d)/(1+r_f) (이자율 평가)
환율 변동성
원/달러 일간 변동폭 ±0.5~1% 수준. 급격한 변동은 수출주 실적에 영향 → 이벤트 드리븐 요소
퀀트 연결: 글로벌 투자 전략에서 환 헤지 여부는 성과에 큰 영향. 원화 약세 → 수출주 수혜 팩터로 모델링 가능
COMM 원자재 (Commodities)
▶
현물가
지금 즉시 인도 기준 가격. WTI 원유 현물, 런던 금 현물 등
선물가
미래 특정 시점에 인도하기로 계약한 가격. 만기일 접근 시 현물가와 수렴
콘탱고
선물가 > 현물가. 정상 상태(보관비용, 이자 반영). ETF 롤오버 시 손실 발생 (롤 비용)
백워데이션
선물가 < 현물가. 공급 부족/급수요 상황. ETF 롤오버 시 이익
원자재 지수
CRB 지수, S&P GSCI, Bloomberg Commodity Index. 원자재 시장 전체 방향성 파악
시장 연결: 유가↑ → 정유·에너지주 수혜, 항공·운송주 부담 / 구리↑ → 경기 확장 신호 / 금↑ → 안전자산 선호 신호
DERIV 파생상품
▶
콜 옵션
특정 가격(행사가)에 기초자산을 살 수 있는 권리. 주가 상승 시 이익. 프리미엄(권리금) 지불
풋 옵션
특정 가격에 기초자산을 팔 수 있는 권리. 주가 하락 헤지 목적. 보험 개념
Black-Scholes
옵션 이론 가격 결정 모델. 입력변수: 기초자산가격(S), 행사가(K), 만기(T), 무위험금리(r), 변동성(σ)
Delta (δ)
기초자산 가격 1원 변화 시 옵션 가격 변화량. 콜: 0~1 / 풋: -1~0. 헤지 비율로 사용
Vega (ν)
내재 변동성(IV) 1%p 변화 시 옵션 가격 변화. IV 상승 시 콜·풋 모두 가격 상승
Theta (θ)
시간 감쇠. 만기까지 1일 경과 시 옵션 가치 감소량. 옵션 매도자에게 유리
C = S·N(d₁) − K·e^(−rT)·N(d₂)
VIX 연결: 변동성지수 VIX는 S&P 500 옵션의 내재변동성. VIX 20+ = 공포 구간. 코스피 200 VIX(VKOSPI)도 동일 원리
RISK 포트폴리오 리스크
▶
VaR
Value at Risk. "X% 신뢰수준에서 N일간 최대 예상 손실 ≤ Y원". 95% VaR 1일 1억 = 5% 확률로 1억 이상 손실 가능
MDD
Maximum Drawdown = 최대 낙폭. 전고점 대비 최저점까지 하락폭. MDD -30% 전략이면 버틸 수 있는지 판단 필수
Sharpe Ratio
(전략 수익률 − 무위험 수익률) ÷ 표준편차. 1 이상이면 우수. 위험 대비 초과 수익 측정
상관관계
-1~1 사이 값. 상관관계 낮은 자산 조합 = 분산투자 효과. 포트폴리오 구성의 핵심
스트레스 테스트
2008 금융위기, 2020 코로나 폭락 구간에서 전략이 어떻게 버텼는지 시뮬레이션. 백테스팅 필수 항목
Sharpe = (Rp − Rf) / σp
MACRO 거시경제 지표
▶
GDP
국내총생산. QoQ/YoY 성장률이 시장 기대치 대비 어떤지가 중요. 예상치 상회 → 주식시장 강세 요인
CPI
소비자물가지수. 인플레이션 핵심 지표. CPI↑ → 금리 인상 압력 → 성장주 밸류에이션 하락 압력
기준금리
한국은행 금통위 결정(연 8회). 금리↑ = 주식 할인율 상승 = PER 하락 압력. 채권가격과 역방향
실업률
낮을수록 경기 호조 신호지만, 너무 낮으면 임금 상승 → 인플레 → 금리 인상 압력
PMI
구매관리자지수. 50 초과 = 경기 확장, 이하 = 수축. 월별 발표. 실물경기 선행지표
BOK ECOS API: 기준금리, CPI, GDP 모두 수집 가능. 거시 데이터와 주가 지수를 결합한 매크로 전략 구현에 필수
NEWS 뉴스 / 센티먼트
▶
Bullish/Bearish
강세(상승 기대) / 약세(하락 기대). Fear & Greed Index, AAII 투자자 심리조사 등으로 측정
뉴스 영향도
공시(실적, IR), 애널리스트 리포트 목표가 변경, 금리 결정문, 지정학적 이벤트 등이 즉각적 주가 반응 유발
이벤트 드리븐
특정 이벤트(어닝 발표, FDA 승인, 계약 공시 등) 전후 가격 움직임을 노리는 전략. 단기 알파의 주요 원천
RAG 연결
LangChain RAG로 뉴스·애널리스트 리포트를 실시간 검색해 LLM 분석에 반영 → 본 프로젝트의 ResearchAgent 역할
수집 소스: 한국경제 RSS, DART 공시 RSS, 네이버 금융 뉴스 API, AgenticSearch(웹 검색) 등 다각도 수집
SCREEN 종목 스크리닝
▶
모멘텀 팩터
최근 6~12개월 수익률 상위 종목 선택. "과거 잘 오른 주식이 앞으로도 오른다"는 실증적 현상
밸류 팩터
낮은 PER, PBR, EV/EBITDA 종목 선택. 저평가된 주식의 평균회귀를 기대. 역발상 투자
퀄리티 팩터
높은 ROE, 낮은 부채비율, 안정적 이익 성장. 방어적 포트폴리오에 적합
복합 스크리닝
RSI < 30 AND MACD 골든크로스 AND 거래량 > 200% — 본 프로젝트 핵심 기능. 최대 5개 조건 조합
업종 비교
섹터 내 상대 순위로 필터링. 반도체 섹터 내 PER 하위 10% 종목 등. 섹터 로테이션 전략의 기본
EVENT M&A / 기업 이벤트
▶
공개매수 (TOB)
Tender Offer Bid. 시장 가격보다 프리미엄(통상 20~30%) 붙여 공개 매수. 발표 즉시 주가 급등. 인수 성공 여부가 핵심 리스크
IPO
기업공개. 상장 첫날 변동성 극심. 따상(시초가 +200%) 현상. 락업(Lock-up) 해제 일정 체크 필수
자본구조 변경
유상증자(신주 발행 → 주가 희석 우려) / 자사주 매입(주가 지지 신호 / EPS 개선) / 액면분할(유동성 개선)
배당 이벤트
배당락일(ex-dividend date) 이전 매수해야 배당 수령. 배당락일 주가는 배당금만큼 하락하는 경향

에이전트 간 데이터 교환, LLM 출력 검증, API 요청/응답 모델링에 Pydantic을 사용합니다. 타입 안전성과 자동 직렬화를 제공합니다.
PYTHON
from pydantic import BaseModel, Field, field_validator, model_validator
from typing import Literal, Optional
from datetime import datetime
from enum import Enum

class SignalType(str, Enum):
    BUY  = "BUY"
    SELL = "SELL"
    HOLD = "HOLD"

# ─── 에이전트 출력 스키마 ───────────────────────────────────
class TradingSignal(BaseModel):
    ticker:      str        = Field(..., min_length=1, max_length=10, description="종목코드 (예: 005930)")
    signal:      SignalType = Field(..., description="매수/매도/보유")
    confidence:  float      = Field(..., ge=0.0, le=1.0, description="신뢰도 0~1")
    price:       float      = Field(..., gt=0, description="신호 발생 시점 주가")
    timestamp:   datetime   = Field(default_factory=datetime.now)
    indicators:  dict[str, float] = Field(default_factory=dict, description="관련 기술지표 값")
    reason:      str        = Field(default="", description="AI 분석 근거")

    @field_validator('ticker')
    @classmethod
    def ticker_uppercase(cls, v: str) -> str:
        return v.strip().upper()

    @field_validator('confidence')
    @classmethod
    def round_confidence(cls, v: float) -> float:
        return round(v, 4)

# ─── 백테스팅 결과 스키마 ──────────────────────────────────
class BacktestResult(BaseModel):
    strategy_name:   str
    start_date:      str
    end_date:        str
    total_return:    float   = Field(description="총 수익률 (%)")
    cagr:            float   = Field(description="연평균 수익률 (%)")
    mdd:             float   = Field(description="최대 낙폭 (%, 음수)")
    sharpe_ratio:    float
    win_rate:        float   = Field(ge=0, le=1)
    total_trades:    int     = Field(ge=0)
    avg_hold_days:   float

    @model_validator(mode='after')
    def validate_mdd(self) -> 'BacktestResult':
        if self.mdd > 0:
            raise ValueError("MDD는 음수여야 합니다 (예: -25.3)")
        return self

# ─── 사용 예시 ─────────────────────────────────────────────
signal = TradingSignal(
    ticker="005930",
    signal=SignalType.BUY,
    confidence=0.86,
    price=88400,
    indicators={"RSI": 28.5, "MACD": -120.3}
)
print(signal.model_dump_json(indent=2))

# ─── Citations 분리 로직 ───────────────────────────────────
class Citation(BaseModel):
    title:   str
    url:     str
    content: Optional[str] = None

def extract_citations_and_text(response) -> tuple[str, list[Citation]]:
    """
    response.choices[0].message에서
    텍스트와 citations를 분리해 반환
    """
    message = response.choices[0].message
    text_parts = []
    citations: list[Citation] = []

    # context 필드에 검색 결과/citations 포함
    if hasattr(message, 'context') and message.context:
        raw_citations = message.context.get('citations', [])
        for c in raw_citations:
            citations.append(Citation(
                title=c.get('title', ''),
                url=c.get('url', ''),
                content=c.get('content', '')
            ))

    # content는 텍스트 (doc_ref 형태로 [doc1] 참조 포함 가능)
    if message.content:
        text_parts.append(message.content)

    return "\n".join(text_parts), citations

analysis_text, citations = extract_citations_and_text(response)

print("=== 분석 결과 ===")
print(analysis_text)
print("\n=== 출처 목록 ===")
for i, c in enumerate(citations, 1):
    print(f"[{i}] {c.title}")
    print(f"    {c.url}")

BASH
# ═══ 포워드 터널 (Local Forwarding) ═══════════════════════
# 로컬 8080 → 원격 서버의 내부 서비스 3000 접근
ssh -L 8080:localhost:3000 user@remote-server.com

# ═══ 리버스 터널 (Remote Forwarding) ══════════════════════
# 로컬 머신의 5000 포트를 원격 서버 9000으로 노출
# (NAT 뒤에 있는 개발 서버를 외부에 임시 노출)
ssh -R 9000:localhost:5000 user@remote-server.com

# ═══ 영구 터널 (AutoSSH / systemd) ═══════════════════════
# 1. autossh 설치
sudo dnf install autossh -y  # RHEL 8

# 2. /etc/systemd/system/ssh-tunnel.service
cat > /etc/systemd/system/ssh-tunnel.service << 'EOF'
[Unit]
Description=SSH Reverse Tunnel to Azure
After=network.target

[Service]
User=tunnel
ExecStart=/usr/bin/autossh -M 0 -N \
  -o "ServerAliveInterval=30" \
  -o "ServerAliveCountMax=3" \
  -o "ExitOnForwardFailure=yes" \
  -R 0.0.0.0:8443:localhost:8000 \
  -i /home/tunnel/.ssh/id_rsa \
  azure-vm-user@YOUR_AZURE_VM_IP
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

systemctl enable --now ssh-tunnel

Slack API — 메시지 발송 (1:1 + 채널 공지)
ReportAgent의 알림 발송 채널로 Slack을 사용. Brevo(이메일)와 함께 투자 리포트 전달 수단.
PYTHON
import os
from slack_sdk import WebClient
from slack_sdk.errors import SlackApiError

# pip install slack_sdk
# Slack App: https://api.slack.com/apps → Bot Token Scopes: chat:write, im:write, users:read

client = WebClient(token=os.environ["SLACK_BOT_TOKEN"])

# ─── 1:1 다이렉트 메시지 ──────────────────────────────────
def send_dm(user_email: str, text: str) -> bool:
    try:
        # 이메일로 user_id 조회
        resp = client.users_lookupByEmail(email=user_email)
        user_id = resp["user"]["id"]

        # DM 채널 열기
        dm = client.conversations_open(users=[user_id])
        channel_id = dm["channel"]["id"]

        # 메시지 발송
        client.chat_postMessage(
            channel=channel_id,
            text=text,
            unfurl_links=False,
        )
        return True
    except SlackApiError as e:
        print(f"Slack 오류: {e.response['error']}")
        return False

# ─── 채널 공지 (Block Kit 리치 메시지) ────────────────────
def send_signal_alert(channel: str, ticker: str, signal: str,
                      price: float, confidence: float, reason: str):
    color = "#00d4aa" if signal == "BUY" else "#f87171"
    emoji = "🟢" if signal == "BUY" else "🔴"

    blocks = [
        {
            "type": "header",
            "text": {"type": "plain_text", "text": f"{emoji} QuantAgent 매매 신호"}
        },
        {
            "type": "section",
            "fields": [
                {"type": "mrkdwn", "text": f"*종목*\n{ticker}"},
                {"type": "mrkdwn", "text": f"*신호*\n{signal}"},
                {"type": "mrkdwn", "text": f"*현재가*\n₩{price:,.0f}"},
                {"type": "mrkdwn", "text": f"*신뢰도*\n{confidence:.0%}"},
            ]
        },
        {"type": "divider"},
        {
            "type": "section",
            "text": {"type": "mrkdwn", "text": f"*분석 근거*\n{reason}"}
        }
    ]

    try:
        client.chat_postMessage(
            channel=channel,
            text=f"{ticker} {signal} 신호",   # fallback text
            blocks=blocks,
            attachments=[{"color": color}]
        )
    except SlackApiError as e:
        print(f"채널 발송 실패: {e.response['error']}")

PYTHON
import os, requests
from datetime import datetime, timedelta
import pandas as pd

# ─── 환경 변수 (.env) ─────────────────────────────────────
# KIS_APP_KEY=PSxxxxxxxx
# KIS_APP_SECRET=xxxxxxxxxxxxxxxxxxxx
# KIS_ACCOUNT_NO=12345678-01  (모의투자 계좌번호)
# KIS_IS_VIRTUAL=true          (모의투자 여부)

BASE_URL_REAL    = "https://openapi.koreainvestment.com:9443"
BASE_URL_VIRTUAL = "https://openapivts.koreainvestment.com:29443"  # 모의투자

def get_base_url() -> str:
    return BASE_URL_VIRTUAL if os.getenv("KIS_IS_VIRTUAL", "true") == "true" else BASE_URL_REAL

# ─── 액세스 토큰 발급 ─────────────────────────────────────
def get_access_token() -> str:
    url = f"{get_base_url()}/oauth2/tokenP"
    body = {
        "grant_type": "client_credentials",
        "appkey":     os.environ["KIS_APP_KEY"],
        "appsecret":  os.environ["KIS_APP_SECRET"],
    }
    resp = requests.post(url, json=body)
    resp.raise_for_status()
    return resp.json()["access_token"]

TOKEN = get_access_token()

def get_headers(tr_id: str) -> dict:
    return {
        "authorization":  f"Bearer {TOKEN}",
        "appkey":          os.environ["KIS_APP_KEY"],
        "appsecret":       os.environ["KIS_APP_SECRET"],
        "tr_id":           tr_id,
        "Content-Type":    "application/json; charset=UTF-8",
    }

# ─── 현재가 조회 ──────────────────────────────────────────
def get_current_price(ticker: str) -> dict:
    """VTTC8434R: 모의투자 주식 현재가 시세"""
    tr_id = "VTTC8434R" if os.getenv("KIS_IS_VIRTUAL") == "true" else "FHKST01010100"
    resp = requests.get(
        f"{get_base_url()}/uapi/domestic-stock/v1/quotations/inquire-price",
        headers=get_headers(tr_id),
        params={
            "FID_COND_MRKT_DIV_CODE": "J",   # J=주식
            "FID_INPUT_ISCD": ticker,
        }
    )
    data = resp.json()["output"]
    return {
        "ticker":  ticker,
        "price":   int(data["stck_prpr"]),     # 현재가
        "open":    int(data["stck_oprc"]),     # 시가
        "high":    int(data["stck_hgpr"]),     # 고가

def get_bok_data(stat_code: str, item_code: str,
                 cycle: str, start: str, end: str) -> pd.DataFrame:
    """
    stat_code  : 통계표 코드  (예: 722Y001 = 기준금리)
    item_code  : 항목 코드    (예: 0101000)
    cycle      : 주기         (M=월, Q=분기, A=연)
    start/end  : YYYYMM 형식
    """
    url = (f"https://ecos.bok.or.kr/api/StatisticSearch/"
           f"{BOK_API_KEY}/json/kr/1/1000/"
           f"{stat_code}/{cycle}/{start}/{end}/{item_code}")
    resp = requests.get(url)
    rows = resp.json()["StatisticSearch"]["row"]
    df = pd.DataFrame(rows)[["TIME","DATA_VALUE"]]
    df.columns = ["date","value"]
    df["value"] = pd.to_numeric(df["value"], errors="coerce")
    return df

PYTHON
"""
gemini_pool.py  —  Gemini API Key Rotation Pool
pip install google-generativeai python-dotenv
"""
import os, time, logging
from itertools import cycle
from threading import Lock
from typing import Optional
from dotenv import load_dotenv
import google.generativeai as genai

load_dotenv()
logger = logging.getLogger(__name__)

# ─── Key Pool 로드 ────────────────────────────────────────
def _load_keys() -> list[str]:
    keys = []
    i = 1
    while True:
        key = os.getenv(f"GEMINI_API_KEY_{i}")
        if not key:
            break
        keys.append(key)
        i += 1
    if not keys:
        raise ValueError("GEMINI_API_KEY_1 이상 환경변수 필요")
    logger.info(f"Gemini Key Pool: {len(keys)}개 로드됨")
    return keys

class GeminiKeyPool:
    """Thread-safe Gemini API Key Rotation Pool"""

    def __init__(self, model_name: str = "gemini-2.0-flash-lite"):
        self._keys       = _load_keys()
        self._pool       = cycle(self._keys)
        self._lock       = Lock()
        self._model_name = model_name
        self._current    = next(self._pool)
        self._exhausted: set[str] = set()

    def _next_key(self) -> Optional[str]:
        """다음 유효한 키 반환. 모두 소진 시 None"""
        with self._lock:
            tried = 0
            while tried < len(self._keys):
                key = next(self._pool)
                if key not in self._exhausted:
                    self._current = key
                    return key
                tried += 1
            return None

    def generate(self, prompt: str, max_retries: int = None) -> str:
        """
        Rate Limit 발생 시 자동으로 다음 키로 교체 후 재시도
        max_retries 기본값 = 보유 키 수
        """
        if max_retries is None:
            max_retries = len(self._keys)

        last_error = None
        for attempt in range(max_retries):
            current_key = self._current
            try:
                genai.configure(api_key=current_key)
                model = genai.GenerativeModel(self._model_name)
                response = model.generate_content(prompt)
                return response.text

            except Exception as e:
                err_str = str(e)
                # Rate Limit 감지
                if any(x in err_str for x in ["429", "RESOURCE_EXHAUSTED",
                                                "quota", "rate limit"]):
                    logger.warning(f"Rate limit (키 #{self._keys.index(current_key)+1}) "
                                   f"→ 다음 키로 교체")
                    self._exhausted.add(current_key)
                    next_key = self._next_key()
                    if next_key is None:
                        logger.error("모든 API 키 소진 → 60초 대기 후 재시도")
                        self._exhausted.clear()  # 리셋 (1분 후 다시 사용 가능)
                        time.sleep(60)
                        self._next_key()
                    time.sleep(1)
                    last_error = e
                else:
                    raise  # 다른 에러는 그대로 전파

        raise Exception(f"모든 재시도 실패. 마지막 오류: {last_error}")

    def get_status(self) -> dict:
        return {
            "total_keys":     len(self._keys),
            "exhausted_keys": len(self._exhausted),
            "active_keys":    len(self._keys) - len(self._exhausted),
            "current_key_idx": self._keys.index(self._current) + 1,
        }

# ─── 전역 인스턴스 (싱글톤) ──────────────────────────────
_pool_instance: Optional[GeminiKeyPool] = None

def get_gemini_pool() -> GeminiKeyPool:
    global _pool_instance
    if _pool_instance is None:
        _pool_instance = GeminiKeyPool()
    return _pool_instance

# ─── LangChain LLM Wrapper (에이전트 연동) ───────────────
from langchain_core.language_models import BaseLLM
from langchain_core.outputs import LLMResult, Generation

class GeminiPoolLLM(BaseLLM):
    """LangChain에서 Key Pool을 사용하는 Gemini LLM"""
    pool: GeminiKeyPool = None

    class Config:
        arbitrary_types_allowed = True

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.pool = get_gemini_pool()

    def _generate(self, prompts, stop=None, **kwargs) -> LLMResult:
        generations = []
        for prompt in prompts:
            text = self.pool.generate(prompt)
            generations.append([Generation(text=text)])
        return LLMResult(generations=generations)

    @property
    def _llm_type(self) -> str:
        return "gemini_pool"

if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO)
    pool = get_gemini_pool()

    # 반복 호출로 Rate Limit 테스트
